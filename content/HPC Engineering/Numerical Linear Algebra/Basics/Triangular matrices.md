### Upper triangular matrix
$$
U = mat(u_(1,1), u_(1,2), dots, u_(1,n) ; 0, u_(2,2),dots, u_(2,n) ; dots.v,, dots.down ,dots.v; 0, 0, dots, u_(n,n)) space.quad   exists U^(- 1) <=> forall i space u_(i,i) != 0
$$
### Lower triangular matrix
$$
L = mat(l_(1,1), 0, dots, 0; l_(2,1), l_(2,2),,0 ; dots.v,dots.v,dots.down, dots.v; l_(n,1), l_(n,2), dots, l_(n,n)) space.quad   exists L^(- 1) <=> forall i space l_(i,i) != 0
$$
### Unitary triangular matrices
$$
U = mat(1, u_(1,2),dots, u_(1,n) ; 0, 1,, u_(2,n) ; dots.v,,dots.down, dots.v; 0, 0, dots, 1)
space.quad 
L = mat(1, 0, dots, 0; l_(2,1), 1,, 0; dots.v,,dots.down, dots.v ; l_(n,1), l_(n,2), dots, 1)
$$
Unitary matrices are always [[Matrix properties#Invertible (non singular)|invertible]].
