### Upper triangular matrix
$$
U = mat(u_(1,1), u_(1,2), ., ., u_(1,n) ; 0, u_(2,2),,, u_(2,n) ; .,, .,, . ; .,,, ., . ; 0, 0, ., ., u_(n,n)) space.quad   exists U^(- 1) <=> forall i space u_(i,i) != 0
$$
### Lower triangular matrix
$$
L = mat(l_(1,1), 0, ., ., 0; l_(2,1), l_(2,2),,, 0 ; .,, .,, . ; .,,, ., . ; l_(n,1), l_(n,2), ., ., l_(n,n)) space.quad   exists L^(- 1) <=> forall i space l_(i,i) != 0
$$
### Unitary triangular matrices
$$
U = mat(1, u_(1,2), ., ., u_(1,n) ; 0, 1,,, u_(2,n) ; .,, .,, . ; .,,, ., . ; 0, 0, ., ., 1)
space.quad 
L = mat(1, 0, ., ., 0; l_(2,1), 1,,, 0 ; .,, .,, . ; .,,, ., . ; l_(n,1), l_(n,2), ., ., 1)
$$
Unitary matrices are always [[Matrix properties#Invertible (non singular)|invertible]].
