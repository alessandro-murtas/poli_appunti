## Invertible (non singular)
A matrix $A in  RR^(n times n)$ is said to be invertible if:
$$
exists  A^(-1) in RR^(n times n): A A^(-1)=A^(-1) A = I
$$
###### Properties
- Given $A, B in RR^{n times n}: (A B)^(-1)=B^(-1) A^(-1)$
- For an invertible matrix $A in RR^(n times n)$ the only solution to the homogeneous linear system $A x=0$ is $x=0$.
## Symmetric
A matrix $A in RR^(n times n)$ is said to be symmetric if $A=A^T$
## Orthogonal
A matrix $A in RR^(n times n)$ is said to be orthogonal if $A A^T=A^T A=I$
